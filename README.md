- Gemini with Groq-hosted Llama 3.3 70B fallback

- PostgreSQL + Prisma
- pgvector-based RAG and semantic retrieval
- FastAPI ML microservice for intent classification
- Automated reports, alerts, and notifications

**Stack:** `Next.js` `FastAPI` `PostgreSQL` `Prisma` `Redis` `BullMQ` `Gemini` `Groq` `pgvector`

A developer productivity platform that transforms GitHub repositories or natural-language ideas into structured technical specifications.

**Highlights**

- OpenAI and Gemini model support
- Streaming generation with Server-Sent Events
- OpenAPI 3.1 + Orval-generated API clients
- PostgreSQL + Drizzle ORM
- GitHub synchronization and webhook integration
- AI-powered document chat and insights
- DOCX, PDF, Markdown, Notion and code-scaffold exports

**Stack:** `React` `TypeScript` `Vite` `Node.js` `Express` `PostgreSQL` `Drizzle` `OpenAI` `Gemini` `SSE`

### ⚡ ExpertBook — Real-Time Expert Booking Platform

A full-stack scheduling platform where experts create event types and clients book sessions with real-time availability.

**Highlights**
- React + Node.js + Express full-stack architecture
- REST APIs for authentication, experts, event types and bookings
- Socket.io real-time booking updates
- Server-side availability validation
- MongoDB / Mongoose persistence
- JWT authentication and role-based access control
- Timezone-aware scheduling
- Calendar `.ics` export
- Gemini-powered expert matching and session summaries

**Stack:** `React` `Vite` `Node.js` `Express` `MongoDB` `Mongoose` `Socket.io` `JWT` `Gemini`

**Highlights**
